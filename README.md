# stm32-robotics-controller
Custom STM32F446 robotics controller PCB for motor control, sensors, and robotics interfaces
## Current Status

Work in progress...

Completed so far:
- STM32F446RET6 MCU selection and core circuitry
- SWD programming/debug interface
- BOOT0 and reset circuitry
- Power architecture planning
- Servo interface planning
- Encoder inputs
- Analog inputs
- Limit / E-stop inputs
- External STEP / DIR / EN motor interface
- CAN communication

## Project Goal

Design a custom robotics controller that integrates common motor, sensor, communication, and debugging interfaces onto one board.
